## 📥 Description

Steam Workshop Downloader is a tool that allows you to download Steam Workshop
items directly without owning the game.

It supports **Wallpaper Engine** and many other games.

This app is built with **Tauri** + **React** and uses:

- **DepotDownloaderMod**

## ✅ Requirements

Before using the app, make sure you have installed:

- [.NET 9.0 Runtime](https://dotnet.microsoft.com/download/dotnet/thank-you/runtime-9.0.0-windows-x64-installer)

## 🚀 Usage

1. Download and install the latest release:

   [➡️ Download v1.0.0](https://github.com/Hikkywannafly/steam-workshop-download/releases/tag/v1.0.0)

2. Go to any Steam Workshop page, such as:

   - Wallpaper Engine
   - Left 4 Dead 2
   - Cities: Skylines
   - Or other supported games

3. Find the mod, map, or workshop item you want to download and copy its URL.

   Example:

   ```txt
   https://steamcommunity.com/sharedfiles/filedetails/?id=3445534475
   ```

4. Open the app and paste the URL into the input box.

   The app will automatically detect the game. If it does not, you can search
   for the game manually.

5. Choose your desired download folder.

6. Click `Download` and wait for the download to finish.
